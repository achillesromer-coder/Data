# Data ACHILLES Orchestration

This folder seeds the non-destructive orchestration layer for the Data repo.

## Role

Data owns repeatable `/wn/data` dataspace pages, structured displays, evidence status, source-pack status and public-safe data views.

## Rule

Data does not replace LinkDrive. Data receives curated exports and displays structured, review-gated information.

No existing file should be deleted or overwritten during scaffold installation.
