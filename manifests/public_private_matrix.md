# Public / Private Matrix

## Purpose

Data can display curated, structured views. It must not replace LinkDrive or expose restricted payloads.

## Status classes

| Status | Meaning |
|---|---|
| internal | working or private only |
| restricted-index | public may see that a category exists, but not the payload |
| review-gated | needs review before public use |
| public-safe | suitable for public display after source and wording checks |
| published | actively displayed on approved web routes |

## Data page rule

Every `/wn/data` page should show:

- source status
- data summary
- evidence grade
- last sync
- related workspace
- related repo
- publication status
